# Data provenance, permissions, and licensing

MindfulBench consists of 253 cases adapted from distinct PsyQA donor records and 467 fresh theory-anchored cases. The original donor records and source IDs are not included in the curated JSONL exports. MindCINS may contain additional source-derived training examples.

The original PsyQA authors' official repository states that full PsyQA access is mediated by a signed data-use agreement. Its 2021 paper states that the dataset is made available to researchers subject to signed ethical guidelines. The right to access a dataset does not necessarily include the right to redistribute derived conversation text. The status of onward distribution permission has **not been verified** here.

Original source: https://github.com/thu-coai/PsyQA
Publication: https://aclanthology.org/2021.findings-acl.130/

**No blanket open-data license is granted in this repository candidate.** GitHub public access does not by itself establish a license to reuse all content. Any license declared by repository owners should reflect confirmed rights to the underlying materials. This notice is not a substitute for the actual agreement.
