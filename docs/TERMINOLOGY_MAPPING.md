# Terminology Mapping

MindfulBench uses stable process codes across historical and paper-facing artifacts. The **paper-facing names below are normative for current README/data-card documentation**. The bundled historical frozen evaluation protocol is preserved byte-identically and therefore retains legacy wording.

| Code | Current paper-facing name | Historical/legacy wording found in frozen artifacts |
|---|---|---|
| S1 | Non-judgment | Non-judgmental noticing |
| S2 | Allowing present experience | Allowing experience |
| S3 | Allowing gradual change | Allowing gradual change |
| S4 | Releasing state-contingent striving | Releasing outcome-driven striving |
| S7 | Letting go of external outcomes | Loosening attachment to outcomes |

The mapping is terminological only. It does not alter historical scores, labels, case assignments, or frozen authority files.
