# Release status — RC4 full-data repository candidate

Files were prepared for direct user GitHub upload on 2026-11-02; no actual publication URL, tag, DOI, publication date or license is confirmed by this package.

**Present:** 720 frozen MindfulBench cases with structured Gold, 4K/6K MindCINS examples, evaluation and training scripts, source and methods documentation, synthetic fixtures and main-panel aggregates.

**Not present:** original complete generated-response banks, item-level historical Judge results, trained adapter weights, exact third-party API backend snapshots and private annotator records.

Some files have historical version suffixes (RC2, RC3, v1.1, v1.2) because they document authentic earlier analysis/protocol steps, not different dataset records included in RC4.
